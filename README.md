# CarePulse - Healthcare & Doctor Appointment Dashboard 🩺

CarePulse is a modern, responsive, and lightweight web front-end application designed for finding specialists and booking online medical appointments. Built using core front-end web technologies, it features dynamic filtering, modal interactions, and persistent local storage.

---

## 🌟 Key Features

* **Interactive Hero Search:** Live filter doctors by name or medical specialty.
* **Specialist Cards Grid:** Clean UI displaying doctor experience, availability status, and ratings.
* **Appointment Booking Modal:** Interactive popup form to select dates and enter patient details.
* **Data Persistence:** Utilizes JavaScript `localStorage` to save booked appointments locally without page refreshes losing state.
* **Fully Responsive Design:** Optimized for mobile, tablet, and desktop views using CSS Flexbox/Grid.

---

## 🛠️ Tech Stack

* **Front-End:** HTML5, CSS3, JavaScript (ES6+)
* **Icons:** FontAwesome v6
* **Typography:** Segoe UI
